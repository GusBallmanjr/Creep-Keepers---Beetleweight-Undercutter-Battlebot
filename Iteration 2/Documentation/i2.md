# Creep Keepers — Beetleweight Undercutter  
## Iteration 2 (Spring 2026 → Completed April 2026)
## Nickname - "Chuckles"

+ Iteration 2 (Chuckles) was the second competitive version following the first iteration used at the fall 2025 Crimson Robotics Bot Brawl. Developed by **Gus Ballman, Carson Roskelley**. This build focused on refining the chassis (removing material), improving internal layout, and improved weapon stack.

## Key Issues Identified
+ Overtensioning of spinner assembly belt
+ Too much friction stemming from bottom chassis support loop for spinner assembly.
+ Lack of space for electronics
+ Difficult to assemble

---

## Lessons Learned
+ Remove support loop for spinner assembly on bottom chassis
+ Need a more robust prototype phase (3d printing and testing model)
+ Need to be able to adjust for tolerances on belt tensioning
